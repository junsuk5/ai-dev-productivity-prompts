# 18. 프로젝트 규칙 업데이트

```text
지금까지 작업하면서 반복적으로 확인된 규칙과 의사결정을 찾아 줘.

앞으로 AI가 이 프로젝트에서 작업할 때 지속적으로 참고할 가치가 있는 내용을 골라 줘.

다음 내용을 찾아 줘.

- 반복해서 지시했던 내용
- 프로젝트 아키텍처상 반드시 지켜야 하는 규칙
- 코드 스타일과 설계 원칙
- 테스트 관련 규칙
- 사용하면 안 되는 접근 방법
- 라이브러리와 의존성 관련 정책
- 반드시 인간의 승인을 받아야 하는 변경

각 후보마다 다음을 설명해 줘.

1. 규칙
2. 이 규칙이 필요한 이유
3. 근거가 된 기존 코드 또는 작업 경험
4. 적용 범위
5. 예외가 필요한 상황

일회성 작업 지시나 근거가 부족한 개인 취향을 영구적인 프로젝트 규칙으로 만들지 마.

기존 프로젝트 규칙과 충돌하는 내용은 자동으로 변경하지 마.

실제 규칙 파일을 수정하기 전에 변경안을 먼저 보여주고 내 승인을 기다려.

```
