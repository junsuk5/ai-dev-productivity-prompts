# 08. 인간 검토 및 승인

```text
지금까지의 분석과 수정 계획을 내가 검토할 수 있도록 정리해 줘.

아직 코드를 수정하지 마.

다음 내용을 중심으로 정리해 줘.

- 해결하려는 문제
- 선택한 해결 방법
- 고려할 수 있는 다른 방법
- 변경될 파일과 코드
- 예상되는 영향
- 주요 위험
- 검증 방법
- 완료 조건
- 내가 직접 결정해야 하는 사항

결정되지 않은 내용을 임의로 선택하지 마.

내가 `승인`, `수정 요청`, `보류` 중 하나를 판단할 수 있을 정도로 정리해 줘.

정리가 끝나면 작업을 시작하지 말고 내 승인을 기다려.

```
