# 04. 문제의 근거 검증

```text
앞에서 발견한 문제들이 실제로 문제가 맞는지 다시 검증해 줘.

아직 코드를 수정하지 마.

각 문제마다 다음 내용을 확인해 줘.

1. 근거가 되는 파일과 코드 위치
2. 코드에서 직접 확인할 수 있는 사실
3. 그 사실로부터 추론한 내용
4. 실제 문제가 발생하는 조건
5. 반대로 문제가 아닐 가능성이 있는 조건
6. 판단 확신도

이전 분석 결과를 방어하려고 하지 마.

근거를 찾을 수 없는 문제는 `근거 부족`이라고 표시해 줘.

일반적인 Best Practice와 다르다는 이유만으로 현재 코드가 잘못됐다고 판단하지 마.

```
