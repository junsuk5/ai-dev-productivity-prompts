# 03. 프로젝트 문제점 분석

```text
현재 프로젝트의 문제점을 찾아 줘.

아직 코드를 수정하지 마.

다음 관점에서 분석해 줘.

- 버그 가능성
- 유지보수성
- 중복 코드
- 아키텍처
- 성능
- 보안
- 테스트 부족
- 예외 처리
- 가독성

각 문제마다 다음 내용을 제시해 줘.

1. 문제
2. 문제가 발견된 파일과 코드 위치
3. 문제라고 판단한 근거
4. 실제로 발생할 수 있는 문제
5. 수정 방향
6. 중요도: Critical / High / Medium / Low
7. 판단 확신도: High / Medium / Low

특히 **코드에서 확인된 사실과 너의 추측을 명확하게 구분해 줘.**

문제의 개수 자체를 늘리려고 하지 말고 실제로 수정할 가치가 있는 문제를 중심으로 찾아 줘.

```
