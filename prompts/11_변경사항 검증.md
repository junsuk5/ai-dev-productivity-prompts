# 11. 변경사항 검증

```text
현재 변경사항이 실제로 요구사항과 완료 조건을 만족하는지 검증해 줘.

새로운 기능을 추가하거나 코드를 개선하려고 하지 말고 먼저 검증에 집중해 줘.

가능한 범위에서 다음을 확인해 줘.

- 관련 테스트 실행
- 전체 또는 관련 프로젝트 빌드
- lint 또는 static analysis
- 기존 테스트 실패 여부
- 변경된 파일과 diff
- 요구사항 충족 여부
- 기존 기능에 영향을 줄 가능성이 높은 부분

각 검증 항목을 다음 중 하나로 표시해 줘.

- PASS
- FAIL
- NOT VERIFIED

검증하지 않은 항목을 성공했다고 표현하지 마.

FAIL이 있으면 작업을 완료했다고 판단하지 마.

```
