# 15. 신규 기능 추가

```text
현재 프로젝트에 `[기능]`을 추가하려고 해.

바로 구현하지 마.

먼저 기존 프로젝트에서 유사한 기능이 어떻게 구현되어 있는지 찾아 줘.

그리고 다음을 분석해 줘.

1. 기존 아키텍처에서 이 기능이 들어갈 위치
2. 재사용할 수 있는 기존 코드
3. 새로 만들어야 하는 코드
4. 변경해야 하는 기존 코드
5. 데이터 흐름
6. 테스트 방법
7. 기존 기능에 미칠 수 있는 영향

가능하면 기존 프로젝트의 코드 스타일과 아키텍처를 유지해.

새로운 라이브러리나 새로운 패턴을 도입해야 한다면 임의로 추가하지 말고 필요성과 대안을 먼저 설명해 줘.

분석 후 구현 계획을 작성하고 내 승인을 기다려.

```
