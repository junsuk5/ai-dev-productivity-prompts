# 17. 반복 작업을 Skill로 만들기

```text
지금까지 반복적으로 수행한 `[작업]`을 재사용 가능한 Skill로 만들어 줘.

Skill은 특정 프로젝트에만 맞춰진 일회성 프롬프트가 아니라 비슷한 프로젝트에서도 사용할 수 있도록 작성해 줘.

다음을 정의해 줘.

- Skill의 목적
- 언제 사용해야 하는지
- 필요한 입력
- 수행 절차
- 반드시 확인해야 하는 항목
- 완료 조건
- 실패했을 때의 처리
- 인간의 승인이 필요한 지점
- 생성하거나 수정할 결과물

특히 지금까지 사람이 반복해서 지시했던 내용을 찾아 명시적인 규칙으로 만들어 줘.

Skill 초안을 먼저 보여주고 바로 적용하지는 마.

```
