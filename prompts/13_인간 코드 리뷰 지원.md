# 13. 인간 코드 리뷰 지원

```text
내가 직접 코드 리뷰를 하려고 해.

이번 작업에서 변경된 내용을 리뷰하기 좋은 순서로 설명해 줘.

전체 코드를 다시 설명하지 말고 다음 내용을 중심으로 정리해 줘.

- 왜 변경했는가
- 핵심 변경 파일
- 중요한 코드 변경
- 기존 동작과 달라진 부분
- 설계상 판단이 필요했던 부분
- 테스트 결과
- 잠재적인 위험
- 내가 직접 확인해야 할 코드

특히 중요한 변경사항은 파일과 코드 위치를 알려 줘.

내가 모든 diff를 동일한 중요도로 읽지 않아도 되도록 **가장 먼저 확인해야 할 부분부터 순서대로** 알려 줘.

```
