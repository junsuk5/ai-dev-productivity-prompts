# 16. 반복 작업 발견

```text
지금까지 수행한 작업을 분석해서 반복적으로 수행하고 있는 작업이나 지시를 찾아 줘.

다음 세 가지로 분류해 줘.

## 프로젝트 규칙으로 만들 것

앞으로 모든 작업에서 지속적으로 지켜야 하는 규칙

## Skill로 만들 것

특정 작업을 할 때 반복적으로 수행하는 절차

## 자동화할 것

사람의 판단 없이 반복 실행해도 되는 작업

각 후보마다 다음을 설명해 줘.

- 현재 반복되고 있는 작업
- 반복되는 빈도
- 자동화했을 때 얻는 이점
- 자동화했을 때의 위험
- Prompt / 프로젝트 규칙 / Skill / 자동화 중 가장 적합한 형태

모든 것을 자동화하려고 하지 말고 인간의 판단이 필요한 작업은 명확하게 구분해 줘.

```
