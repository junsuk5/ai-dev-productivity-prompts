# 09. 진척도 관리 파일 작성

```text
승인한 작업 계획을 기반으로 프로젝트 루트에 `PROGRESS.md`를 만들어 줘.

다음 내용을 기록해 줘.

- 프로젝트 개선 목표
- 전체 Task
- 현재 상태
- 완료된 작업
- 진행 중인 작업
- 아직 시작하지 않은 작업
- 발견된 추가 문제
- 주요 의사결정
- 검증 결과

Task 상태는 다음 세 가지를 사용해.

- TODO
- IN PROGRESS
- DONE

각 Task에는 반드시 완료 조건을 기록해 줘.

앞으로 작업을 시작하거나 완료할 때마다 이 파일을 업데이트해서 새로운 AI 세션에서도 현재 진행 상황을 파악할 수 있도록 해 줘.

완료 조건을 만족하지 않은 Task를 DONE으로 표시하지 마.

파일을 작성한 후 아직 코드 수정은 시작하지 마.

```
