# 12. AI 자기 리뷰

```text
방금 수행한 작업을 리뷰해 줘.

새로운 코드를 작성하거나 수정하지 마.

최초 작업 계획, 완료 조건, 실제 변경사항을 서로 비교해 줘.

다음을 확인해.

1. 계획대로 완료된 항목
2. 계획과 다르게 구현된 항목
3. 아직 완료되지 않은 항목
4. 요구하지 않았는데 변경된 부분
5. 불필요하게 복잡해진 코드
6. 테스트가 부족한 부분
7. 기존 기능에 영향을 줄 가능성이 있는 부분
8. 내가 직접 확인해야 할 부분

특히 네가 작성한 코드라고 해서 옹호하지 말고 코드 리뷰어의 입장에서 비판적으로 검토해 줘.

마지막으로 이 작업을 다음 중 하나로 평가하고 근거를 제시해 줘.

- 승인 가능
- 수정 후 승인
- 재작업 필요

```
