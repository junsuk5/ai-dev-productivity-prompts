# 10. 작은 단위로 구현

```text
`PROGRESS.md`에서 다음 Task를 수행해 줘.

`[Task 이름]`

먼저 Task의 목표와 완료 조건을 다시 확인해.

필요한 코드만 수정하고 이 Task와 관계없는 리팩터링은 하지 마.

작업 후 다음을 수행해 줘.

1. 관련 테스트 실행
2. 프로젝트 빌드 확인
3. 정적 분석 또는 lint 확인
4. 변경된 파일 확인
5. Task의 완료 조건 충족 여부 확인

검증에 실패하면 문제를 숨기거나 Task를 완료 처리하지 마.

작업 결과와 검증 결과를 `PROGRESS.md`에 업데이트해 줘.

```
