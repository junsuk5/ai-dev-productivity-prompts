# 02. 요구사항과 제약조건 추출

```text
현재 요청된 작업을 분석해서 구현 전에 알아야 할 요구사항과 제약조건을 정리해 줘.

아직 코드를 수정하지 마.

다음 내용을 찾아 줘.

- 명시적으로 요구된 기능
- 기존 동작 중 유지해야 하는 부분
- 기술적으로 지켜야 하는 제약
- 완료 여부를 판단할 수 있는 조건
- 요구사항에서 명확하지 않은 부분
- 구현 전에 추가로 확인해야 할 내용

요구사항에 직접 적혀 있는 내용과 네가 추론한 내용을 구분해 줘.

불명확한 내용을 임의로 결정하지 말고 `확인 필요`라고 표시해 줘.

```
